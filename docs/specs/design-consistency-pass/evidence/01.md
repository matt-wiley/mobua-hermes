## AC-53: every table has a Reader id except declared exemptions; Channel-owned tables have a Channel id

**Tests** (`tests/service/test_schema.py`, against the Alembic-migrated SQLite database):
- `test_migration_creates_the_revisioned_channel_and_plugin_tables`
- `test_every_table_has_a_reader_id_except_declared_exemptions`
- `test_every_exemption_names_a_real_table`
- `test_tables_referencing_a_channel_or_its_revisions_have_a_channel_id`
- `test_migrated_schema_matches_the_models`
- `test_sqlite_runs_in_wal_mode`
- `test_sqlite_enforces_foreign_keys`
- `test_migration_downgrades_to_an_empty_database`

**Categories**
- Happy path: the schema test passes on the migrated database.
- Failure mode: if a table lacks `reader_id` or `channel_id`, the test lists it.
- Guard against drift:
  - stale exemptions are caught;
  - the Channel-owned check finds tables by their foreign keys to `channel` or `channel_revision`, not by a hand-kept list, and asserts that at least one exists so it cannot pass vacuously;
  - model and migration drift is caught by `compare_metadata`.
- Edge cases:
  - Built-in Plugin rows share the `plugin` and `plugin_revision` tables with a nullable `reader_id` (ADR 0019), so those tables keep the column;
  - declared exemptions are `alembic_version` (app-wide) and `reader` (its id is the Reader id).

**Red** (empty migration history, stub engine without pragmas):
```

E       AssertionError: expected at least one Channel-owned table
E           AssertionError: assert 'delete' == 'wal'
E           AssertionError: assert 0 == 1        (foreign_keys pragma)
```
**Green:** `7 passed`. The downgrade test was added after the green and passed on its first run. It is a regression guard and not red-first, because the downgrade was autogenerated alongside the upgrade.
